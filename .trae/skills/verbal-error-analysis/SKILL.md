# 言语错题分析（薄包装）

1. 完整读取本仓库根目录的《错题分析准则-言语理解.md》——它是唯一权威判案规范，本 skill 不重复其内容。
2. 按准则 §2 三档判定判案，禁止在准则未覆盖处强行套用框架。
3. 按准则 §5-§7 完成错题卡入库、词语入库、同步、校验与提交。
4. 若准则文件缺失或被移动：向用户报告路径问题，不要凭记忆重建内容。

> **可迁移性**：判案内容全部保存在项目文件《错题分析准则-言语理解.md》。更换 AI 工具时，带走整个项目文件夹，或单独把该 md 交给任何 AI 并说明「按此准则分析错题」，即可获得一致判案。
