五次反围剿

五次反"围剿"是理解红军早期作战逻辑与后来长征起源的关键。核心线索是：前四次靠同一套"诱敌深入"的运动战逻辑取胜，第五次则因为决策权转移，抛弃了这套逻辑，最终导致失败与长征。

来源板块：近现代史 · 新民主主义革命时期 · 五次反围剿
前四次胜利 = 诱敌深入 + 运动战 + 集中优势兵力；第五次失败 = 放弃诱敌深入 + 阵地战 + 分兵把口。当正确的战术原则被教条主义的指挥所取代时，红军付出了丢掉中央苏区、被迫长征的代价。
第一层 · 发生学

痛点：红军和革命根据地的发展，招致国民党调集重兵"围剿"——包围和清剿；红军兵力、装备均处劣势，正面硬拼必败。目的：打破包围清剿，保存并发展革命力量。破局之道是毛泽东、朱德提出的"诱敌深入"：不死守城池、主动退却，将敌军拖入根据地内部，利用其兵力分散、补给困难的弱点，集中优势兵力在运动中各个歼灭。

第二层 · 结构拆解

名称解释："围剿"是国民党方面的军事术语（调集重兵包围清剿）；"反围剿"是红军视角的对应说法。国民党战史称"围剿"（如"第五次围剿"），中共战史称"反围剿"，名称差异本身反映双方对同一场战争的不同立场与叙事。前四次战例：

  • 第一次（1930.11-1931.1）：蒋调10万余人"长驱直入"；红军4万余人诱敌深入，龙冈全歼国民党第18师、活捉师长张辉瓒，共歼敌1.5万人。
  • 第二次（1931.4-5）：何应钦率20万大军"稳扎稳打、步步为营"；红军3万余人东固隐蔽待命20多天，从富田打起，半个月横扫七百里、五战五捷，歼敌3万余人。
  • 第三次（1931.7-9）：蒋介石亲任总司令率30万大军"长驱直入"；红军千里回师赣南，用"磨盘战术"（避敌主力、打其虚弱），连打三个胜仗，歼敌3万余人。
  • 第四次（1932.12-1933.3）：国民党近40万兵力"分进合击"；毛泽东已被排挤出军事指挥岗位，但周恩来、朱德抵制临时中央强攻南丰的命令，改用大兵团伏击战，黄陂、草台岗两仗歼灭国民党嫡系近3个师、俘敌1万余人。
第三层 · 发生学迭代
  • 前四次：同一套逻辑的重复胜利（1930-1933）："诱敌深入+运动战+集中优势兵力"连胜，根据地不断巩固扩大。
  • 第五次：逻辑的断裂（1933-1934）：博古不懂军事，指挥权交给共产国际军事顾问李德，放弃"诱敌深入"，改行"御敌于国门之外"的军事冒险主义，打阵地战、堡垒战，受挫后又变为分兵把口的单纯防御，与优势敌军拼消耗。
  • 结局：被迫长征：苦战一年始终无法打破围剿，根据地日益缩小，1934年10月被迫放弃中央苏区、开始长征。
第四层 · 因果传导链
胜利链：诱敌深入 → 拖入根据地 → 集中优势兵力运动中歼敌 → 前四次打破围剿。
失败链：博古+李德（教条主义指挥）→ 放弃诱敌深入 → 御敌于国门之外（阵地战、堡垒战）→ 受挫后分兵把口 → 拼消耗陷入被动 → 第五次反围剿失败 → 中央苏区丢失 → 1934年10月长征开始 → 湘江惨败 → 遵义会议（系统总结失败、重新确立正确军事路线）。
高频考法：① 前四次胜利的战术——"诱敌深入、运动战、集中优势兵力"；② 第五次失败原因——博古、李德放弃诱敌深入，改行"御敌于国门之外"的阵地战、堡垒战（军事冒险主义+单纯防御）；③ 张冠李戴——第五次反围剿失败不是因为敌人更强（蒋调集100万大军、50万重点进攻中央苏区），而是红军自己抛弃了正确战术逻辑；④ 数据易错：第一次10万/4万、第二次20万/3万、第三次30万、第四次40万；⑤ 第五次反围剿失败是长征与遵义会议的因果前提。
