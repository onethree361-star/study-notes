决策

西蒙说"管理就是决策"。本页把决策的全部家当分成两半：知（第一、二层）装下基本概念与整套工具箱——六步过程、两种分类、一整箱选择方法；行（第三层）用"奶茶店要不要开第二家分店"这件事，按你现实生活中遇到事情的真实顺序，把每个工具亲自用一遍。

来源板块：管理学 · 决策
你开了一家奶茶店，生意不错，隔壁商场招租——开不开第二家分店？这个"要不要"，就是决策。小到中午吃什么，大到报哪个岗位、去哪个城市，人生就是一连串决策；管理者更是天天在"选方案、批项目、用人"——所以西蒙干脆说：管理就是决策。
第一层 · 发生学【知：决策为什么是管理的核心】

宏观痛点：资源有限、未来不确定、信息不完全——同一笔钱有三种花法、同一个岗位有三个人选，不选不行，选了就可能错。凡是"有多个可选、必须拍板"的时刻，都是决策。
宏观目的：给"拍板"这件事装上流程和工具——先有六步过程保证不乱拍，再有分类方法保证不同处境用不同的算法。

西蒙的修正：古典经济学假设人是"完全理性经济人"，能算出最优解；西蒙指出人只拥有有限理性——信息、精力、时间都有限，所以现实中决策追求的是满意解，不是最优解。这是决策理论学派的根基，也是"管理就是决策"这句话的出处。
第二层 · 结构拆解【知：决策知识全景】
1. 决策过程：六步
决策六步：识别问题 → 诊断原因 → 确定目标 → 制定备选方案 → 评价、选择方案 → 实施和监督
2. 决策分类：两个维度

按决策目标的影响程度（从大到小）：
战略决策（最重要）——组织目标、方针的确定，组织机构的调整，企业产品的更新换代，技术改造等，决定全局方向；
战术决策——企业生产计划和销售计划的制定、设备的更新、新产品的定价以及资金的筹措等，为战略服务；
业务决策——日常工作中为提高生产效率、工作效率作出的决策，牵涉范围较窄、只对组织产生局部影响：工作任务的日常分配和检查、工作日程（生产进度）的安排和监督、岗位责任制的制定和执行、库存的控制以及材料的采购等。

按决策条件的可控程度（核心看"知不知道概率"）：
确定型决策——决策环境完全确定，对各备选方案的自然状态和结果有明确认知，每个方案仅有唯一确定结果；
风险型决策——存在多种可能的自然状态，每种状态的发生概率已知或可估计，但最终结果具有不确定性；
不确定型决策——存在多种可能的自然状态，但每种状态的发生概率完全未知。

3. 行动方案选择的决策方法：先判断类型，再配工具

确定型 → 盈亏平衡点法：成本收入都确定，算出"销量达到多少才保本"，以此为线选方案。
风险型 → 决策树法：画出方案分支，按各状态概率算期望收益，取期望值最大的分支。
不确定型 → 四条原则：① 乐观原则（最大收益值原则）——赌最好的结果，选"好上加好"的方案；② 悲观原则（小中取大原则 / 最大最小收益值原则）——先看每个方案最坏能拿多少，再从坏结果里挑最好的；③ 折中原则——在最好与最坏之间按系数加权，不赌满也不保底；④ "最大后悔值"最小化原则——算出"事后没选它会多后悔多少"，选最坏情况下后悔最小的。

4. 确定活动方向和内容的决策方法

安德鲁斯的 SWOT 分析法——先盘家底再定方向：
SO 型（优势＋机会）：企业具有良好的外部机会及有利的内部条件 → 采用增长型战略，乘势扩张；
WO 型（劣势＋机会）：有良好的外部机会，却受内部劣势限制 → 采取扭转型战略，先补短板抓住机会；
WT 型（劣势＋威胁）：内部存在劣势，外部面临巨大威胁 → 采取防御型战略，收缩自保；
ST 型（优势＋威胁）：具有内部实力，但外部环境存在威胁 → 宜采用多种经营战略（多角经营），把实力用到别处。

波士顿矩阵分析法——用两个维度（市场占有率 × 业务增长率）给业务分家：
"金牛"业务：占有率高、增长率低，能源源不断产生高额利润和现金回笼 → 维持策略，拿它当提款机；
"明星"业务：占有率和增长率都高 → 不失时机投入资金扩大规模，扩张战略；
"幼童"业务：增长率高、占有率低，赌前途——①有前途：投入必要资金，采取扩张战略；②无前途：采取放弃策略；
"瘦狗"业务：占有率和增长率都低，只能带来很少的现金和利润，甚至亏损 → 收缩甚至放弃。

5. 集体决策方法：四个"开会开得更聪明"的工具

头脑风暴法——特点：倡导创新思维，先求数量不求质量。四项原则：①各自发表自己的意见，对别人的建议不作评论；②建议不必深思熟虑，越多越好；③鼓励独立思考、奇思妙想；④可以补充完善已有的建议，使之更具说服力。

名义小组法——对群体成员的讨论或人际沟通加以限制，但成员独立思考（"名义上是小组，实际各想各的"）。实施步骤：

名义小组五步：组成小组 → 独立思考与提出方案 → 阐述方案 → 提问与讨论 → 投票表决

德尔菲法（也称专家调查法）——广泛应用于预测和决策：基于专家的知识与经验，通过系统的流程（匿名函询、多轮反馈）得出可靠结论。三大特征：匿名性、反馈性、统计性——专家背对背，谁也不知道谁说了什么，避免权威罩场子和面子拉扯。

电子会议分析法——参与者围坐在桌旁，面前除了一台计算机终端外无其他物品；问题通过大屏幕呈现，把自己的回答输入计算机，匿名的投票结果实时显示在屏幕上——名义小组法的电子化提速版。

6. 快速决策分析法：来不及慢慢算怎么办

贝恩和沃普尔提出：在时间和信息不充分的条件下迅速做出决策的分析方法——强调对决策问题的整体思考和结构化，注重运用正确的分析过程。机会窗口只有几天时，不追求每个数据精确，先搭框架、再填要点、快速收敛。

第三层 · 发生学迭代【行：跟着"开分店"走一遍六步】

决策工具的迭代方向是"从拍脑袋到结构化"；而工具用法，最好的记法是按你遇到事情的真实顺序走一遍。场景：奶茶店生意不错，隔壁商场招租——要不要开第二家分店？

第 1 步 · 识别问题：先分清这是"问题"还是"机会"

老店天天排队＝需求外溢，商场招租＝机会窗口。识别环节最大的坑是把症状当问题：以为是"客流少了"，其实是隔壁新开的奶茶店分流——病没找对，药全白开。顺带分类：开分店对你这家小店是天大的事（战略级）；对蜜雪冰城总部只是战术决策，对店长排班则是业务决策——影响程度是相对的，看站在谁的立场上。

第 2 步 · 诊断原因：用 SWOT 摸清家底

开不开不能凭感觉，先摊牌：S 优势——口味有口碑、老客稳定；W 劣势——钱不多、缺可信的店长人选；O 机会——商场招租、人流汇聚；T 威胁——商场客流有波动、竞品可能跟进进驻。诊断完你会发现：SO（有口碑又赶上招租）在向你招手，WT（没钱又怕客流不稳）在拉你后袖——方向类工具（SWOT、波士顿矩阵）就是用在这一步。

第 3 步 · 确定目标：把"开个店"翻译成能验收的数字

"开一家新店"不是目标，是愿望。目标要能验收：一年内收回 30 万投入、日均营业额 5000、新店长带教合格上岗——目标定成什么样，直接决定第五步用什么标准去评价方案（呼应计划的 SMART）。

第 4 步 · 制定备选方案：多想几条路，别只会"开或不开"

一个人拍脑袋只有 A/B 两个选项；备选越充分，选出来的方案越可能是"满意解"。拉人一起想的三个姿势：头脑风暴——店员、供货商、开过店的朋友各自出主意，规则是不许评论、越多越好；德尔菲——朋友碍于面子当面不好驳你，改成匿名函询，几轮下来意见收敛；名义小组——几方吵不出结果时，各自独立写方案、阐述、提问讨论、投票表决。最后凑出三条路：A 开商场店 ／ B 老店加做外卖 ／ C 维持现状攒钱。

第 5 步 · 评价、选择方案：先看信息条件，再挑算法

这是决策的心脏，考得最凶。三条路摆好，先问自己：信息够不够？
A 商场店的成本、租金都谈死了，销量达到每月 4000 杯才保本——条件确定，用盈亏平衡点法，B 方案外卖增量算不出保本线就出局；
商场客流有火、平、冷三种可能，概率能估（五成平、三成火、两成冷）——概率已知，是风险型，画决策树算期望收益；
新商圈没人说得准，概率完全未知——不确定型，用四原则：乐观原则看"最好能赚多少"（赌徒打法）；悲观原则看"最坏能接受吗"、从坏结果里挑最好的（保守打法，小中取大）；折中原则在最好最坏之间打系数；后悔值原则问"一年后回头看，哪个选项最不后悔"，选最大后悔值最小的那个。你的性格偏保守——悲观原则和后悔值原则更配你。

第 6 步 · 实施和监督：拍板不是结束，是开始

签约、装修、招人、开业——然后每月对账：营业额没到线就找原因纠偏，连续两月不达标就考虑收缩（这就是控制职能的前馈＋反馈控制，PDCA 滚起来）。决策不是"拍板那一刻"，是"拍板后持续盯着"——监督环节的反馈，会成为你下一轮决策的输入。

现实加戏：商场只给你一周时间呢？——时间、信息都不充分，六步走不完整套，就上快速决策分析法（贝恩和沃普尔）：整体思考＋结构化，先搭"目标—方案—风险"的框架再填要点。最后记住西蒙：人是有限理性的，别追求最优解，够满意就拍板——错过窗口的"最优"，不如及时落地的"满意"。
第四层 · 因果传导链
链条一：好决策的闭环
问题识别准（机会/问题分得清） → 诊断到位（SWOT 摊开家底） → 目标清晰可验收 → 备选充分（≥2 条路） → 选择原则与信息条件匹配 → 实施有监督 → 结果可纠偏 → 反馈喂给下一轮决策 → 越决策越准。
链条二：坏决策从第一步就歪
把症状当问题（客流少？其实是隔壁分流） → 诊断错位 → 目标模糊（"把生意做大"） → 方案单一（只剩"开或不开"二选一） → 凭感觉拍板 → 拍完没人盯 → 小错滚成大错。
机制：六步里任何一步偷懒，代价都会在后面某一步加倍讨回来——流程不是形式，是挡错误的闸门。
链条三：工具错配灾难
概率完全未知却硬用决策树（伪精确） → 算出的期望值给人虚假安全感 → 过度自信押重注 → 翻车；反过来，条件明确的例行小事却反复开会头脑风暴 → 效率底下，错过窗口。
铁律：先判断决策类型，再挑工具——确定型配盈亏平衡、风险型配决策树、不确定型配四原则；方向类用 SWOT/波士顿，集体出主意用脑名德电——先分类，后开方。
终极口诀：六步"识诊目备评监"，一步不能乱；分类两把尺——影响大小分战略战术业务，概率知否分确定风险不确定；不确定型四原则"乐观取最大、悲观小中取大、折中打系数、后悔选最小"；集体决策"脑名德电"——头脑风暴求量不点评、名义小组独立写完再投票、德尔菲匿名函询有反馈、电子会议电脑匿名实时显；SWOT"SO增长、WO扭转、WT防御、ST多角"；波士顿"金牛维持、明星扩张、幼童赌前途、瘦狗快收缩"。
常见设错：说决策追求"最优解"（错，西蒙有限理性→满意解）；概率已知却选不确定型四原则、概率未知却用决策树（错，先看概率再配工具）；德尔菲＝专家当面讨论（错，匿名函询背对背）；头脑风暴"对别人建议及时点评"（错，不作评论）；波士顿两维度说成利润率×增长率（错，市场占有率×业务增长率）；名义小组＝完全不许交流（错，是限制讨论、可阐述提问后投票）；战略决策由基层管理者做（错，高层定战略、基层管日常业务决策）。
