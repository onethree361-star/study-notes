人性假设谱系

管理学是一部"人性假设的辩论史"——你怎么看人，就怎么管人：先回答"人是什么"（经济人→社会人→自我实现人→复杂人→知识人），管理手段就跟着换（大棒→参与→授权→权变→赋能）。

来源板块：管理学 · 管理思想谱系
你开了一家奶茶店，招了两个店员。你觉得他们"天生偷懒只为钱"，就会装摄像头、迟到罚款、多卖一杯提成——店员确实卖力了，但绝不多干一分。后来你换了个思路：他们其实在乎被尊重、想学本事，于是改成当众表扬、教他们做新品、让他们排班——他们开始主动想办法留住客人。同一个人，你对他的"假设"变了，管理手段就全变了。
第一层 · 发生学

宏观痛点：一切管理手段都建立在"对人的假设"上——定工资制度、设计考核、选择领导风格之前，管理者必须先回答"员工是什么样的人"。假设错了，手段全错。
宏观目的：管理学沿着历史顺序给出五套答案（经济人→社会人→自我实现人→复杂人→知识人），每一套假设都对应一整套管理手段——这就是学说史演变的底层发动机。

个人视角：对你意味着什么：你带实习生的第一步不是选手段，而是先自问"我默认TA是什么人"。默认TA偷懒，你就会事事盯梢，TA果然只做最低限度；默认TA想成长，你就会给解释和空间，TA反而更主动——假设会自我实现。
第二层 · 结构拆解
1. 经济人假设（X理论）

人性判断：人天生懒惰、追求经济利益最大化。管理对策：胡萝卜加大棒——动作研究＋定额＋差别计件工资。代表：泰勒·科学管理（X理论由麦格雷戈命名归纳）。

2. 社会人假设

人性判断：人要归属感、被关注，人际关系比金钱更能调动积极性。管理对策：参与管理、倾听沟通、正视非正式组织。代表：梅奥·霍桑实验。

3. 自我实现人假设（Y理论）

人性判断：人愿意主动发挥潜能、对工作负责，工作是像游戏一样自然的需求。管理对策：授权、工作丰富化、创造自我实现的条件。代表：马斯洛·需要层次（假设来源）、麦格雷戈·Y理论（管理主张）。

4. 复杂人假设（超Y理论 / 权变）

人性判断：人的需求因人、因时、因境而变，没有统一模板。管理对策：权变管理——一把钥匙开一把锁。代表：沙因（归纳提出）、莫尔斯与洛希（超Y理论实验）。

5. 知识人假设

人性判断：知识工作者掌握生产资料（脑中知识），必须自我管理。管理对策：目标管理（MBO）、赋能、建设学习型组织。代表：德鲁克、彼得·圣吉。

第三层 · 发生学迭代
  • 1.0 经济人（1911，科学管理）：把人当机器的延伸，标准化＋金钱刺激。有效但副作用大：工人变成流水线上的"手"，干得越多越麻木。
  • 2.0 社会人（1930s，霍桑实验）：梅奥发现照明再亮再暗产量都涨——真正起作用的是"被关注"和班组里的非正式组织。"人是机器"被推翻，管理第一次开始"看人"。
  • 3.0 自我实现人（1950s，Y理论）：既然人有更高层需求，那就别再管手，去释放潜能——授权、工作丰富化登场。
  • 4.0 复杂人（1960-70s，权变）：人们发现前三套都对也都不全对——需求因人而异，于是放弃"万能公式"，转向"看人下菜"的权变。
  • 5.0 知识人（1980s后）：知识经济到来，员工脑子里装着比老板更多的专业知识——只能靠目标对齐与赋能，不能靠盯。
修正误区：迭代不是"后面的推翻前面的"，而是新假设覆盖了旧假设管不到的场景——计件工资在车间依然好用（经济人逻辑），但对研发人员就是灾难（要用知识人逻辑）。考"权变"就是考这个：没有万能公式，匹配才是王道。
第四层 · 因果传导链
链条一：X假设的恶性循环（自我实现的预言）
管理者认定"人懒"（X假设） → 层层监控＋惩罚 → 员工感到不被信任 → 只出工不出力，绝不主动多干一分 → 管理者更确信"看吧人就是懒" → 监控加码。
机制：假设 → 手段 → 行为反馈 → 假设被"验证"——你越相信什么，越会把它变成现实。
链条二：Y假设的良性循环
管理者假设"人想成长"（Y假设） → 授权＋给成长台阶 → 员工被激发、主动补位 → 业绩提升 → 更敢授权 → 人才辈出。
机制：正向假设同样自我实现——信任产生配得上信任的行为。
链条三：错配灾难（权变才是铁律）
对知识人用经济人手段（打卡计件、事事审批） → 人才流失；对松散体力活用知识人手段（完全放养） → 出工不出力。
铁律：管理手段必须与员工成熟度＋任务性质匹配——新人盯过程（X式带教），骨干看结果（Y式授权）。
终极口诀：经济人懒为钱干，泰勒大棒又加糖；社会人要归属感，梅奥霍桑士气涨；自我实现马斯洛，麦格雷戈Y主张；复杂人多变看情境，权变沙因一把钥匙一把锁；知识人自管理，德鲁克目标加赋能——你怎么看人，就怎么管人！
常见设错：把霍桑实验安给泰勒（错，是梅奥）；说Y理论由马斯洛提出（错，马斯洛是假设来源，提出者是麦格雷戈）；经济人假设下应多授权（错，经济人对应控制与经济刺激，授权对应自我实现人/知识人）。
