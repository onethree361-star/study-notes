数据结构到底研究什么

数据结构 = 数据元素 + 元素间的关系 + 关系上的操作。定义里"一种或多种特定关系"这几个字，就是集合、线性、树、图的全部区别。

记住一句：换存储不改逻辑，只改快慢。线性表用数组还是链表，逻辑上都是"一对一排队"。

一、物理结构（存储结构）

顺序 · 链式 · 索引 · 散列

1.1 四种存储方式

物理结构指数据及其关系在内存中的实际表示。四类：顺序、链式、索引、散列。

存储方式关系怎么表示取第 i 个插入/删除典型载体
顺序物理相邻 = 逻辑相邻O(1) 算地址O(n) 挪数据数组、顺序表
链式指针指向下一个O(n) 从头走O(1) 改指针（先找到位置）单/双链表
索引索引项指向数据块先查索引再定位要维护索引表数据库索引、分块查找
散列由关键字算出地址平均 O(1)平均 O(1)，冲突时退化HashMap、Redis

二、逻辑结构

线性 · 树 · 图 · 哈希

2.1 总览：集合、线性、树、图

线性：一对一，每个元素最多一个直接前驱、一个直接后继。非线性：一对多（树）或多对多（图）。

判断只看关系：栈、队列、串、数组、顺序表、链表都是线性；二叉树、堆、图是非线性。

2.2 线性表：顺序表与链表

线性表是有序的元素集合。两种实现：顺序表（一段连续内存）、链表（节点散放、指针相连）。

维度顺序表链表
取第 i 个O(1)，算地址O(n)，逐个数
插入/删除O(n)，挪元素O(1)，改指针（定位仍要 O(n)）
空间要连续，可能扩容搬家不必连续，每节点多存一个指针
能折半查找吗能（前提有序）不能，没法跳着取

考点："链表插入删除快"说的是改指针那一步，找到位置本身仍要 O(n)；链表不能随机访问，也不能折半。

2.3 栈与队列

栈：只在一端（栈顶）进出，后进先出。队列：一端进（队尾）、另一端出（队头），先进先出。

应用：栈——括号匹配、表达式求值、函数调用、页面后退、DFS；队列——打印缓冲、消息排队、任务调度、BFS。

考点：给入栈顺序判"哪种出栈序列不可能"。记住后进先出，别把它当成排队。

2.4 树与二叉树

树是层级结构：一个根，每个节点最多一个父节点、可有多个子节点。度 = 该节点的子树数；深度 = 从根往下数几层；高度 = 从该节点到最深叶子数几层。

类型一句话判别典型用途
满二叉树每层都满，叶子全在最底层性质计算、编号题
完全二叉树只有最后一层可以不满，且靠左堆、数组存树
二叉搜索树 BST左子树全小、右子树全大查找，中序递增
平衡二叉树每个节点左右子树高度差 ≤ 1防退化（AVL）
堆完全二叉树 + 父节点恒大（或恒小）优先队列、堆排

四条性质最常考：n₀ = n₂ + 1（叶子数 = 度为 2 的节点数 + 1）；第 i 层最多 2i-1 个；深度 k 最多 2k-1 个；完全二叉树深度 = ⌊log₂n⌋ + 1。

2.5 四种遍历

遍历 = 每个节点访问一次。先序根左右、中序左根右、后序左右根；层序按层从上到下、从左到右，用队列。

void preOrder(BiTree T) {          // 先序：把 visit 挪动位置就是中序/后序
    if (!T) return;
    visit(T);                      // 先序在这；中序挪到下一行之后；后序挪到最后
    preOrder(T->lchild);
    preOrder(T->rchild);
}

void levelOrder(BiTree T) {        // 层序：队列，出一个就把孩子塞进去
    Queue Q; init(Q); enQueue(Q, T);
    while (!isEmpty(Q)) {
        p = deQueue(Q); visit(p);
        if (p->lchild) enQueue(Q, p->lchild);
        if (p->rchild) enQueue(Q, p->rchild);
    }
}

必考结论：中序 + 先序（或后序、层序）能唯一确定一棵树；只给先序和后序，定不出来（分不清左右）。

2.6 堆

堆 = 完全二叉树 + 堆序：大根堆每个父节点 ≥ 子节点（根最大），小根堆反过来。数组存，下标 0 起：左孩子 2i+1、右孩子 2i+2。

用途：优先队列、堆排序、Top-K（求最大 K 个用小根堆，堆顶就是第 K 名）、Dijkstra / Prim 的辅助结构。

2.7 图：存储与遍历

图 = 顶点 + 边，可以随便连、可以有环。有向图看入度（指向自己）和出度（自己指出去）。

考点：稠密图用邻接矩阵、稀疏图用邻接表；有向图的度必须分入度和出度，别混成一个数。

2.8 图的三类算法

三类问题、七种算法，考的是"什么图、用什么、复杂度多少"。

问题算法怎么干适合 / 限制复杂度
最小生成树
（边 = 顶点数 - 1）		Prim从一个点出发，每次挑连接"已选"与"未选"的最小边稠密图O(n²)
Kruskal所有边排序，从小到大挑，不成环就留下稀疏图O(e log e)
最短路径Dijkstra从源点逐步确定最近点单源、不能有负权O(n²)
Bellman-Ford反复松弛所有边可处理负权、能判负环O(n·e)
Floyd三重循环，逐个点当"中转站"多源任意两点O(n³)
拓扑排序入度法入度为 0 的入队，出队后把它指向的入度减 1只适用有向无环图O(n+e)

三句话：Prim 盯点、Kruskal 挑边；有负权边就别用 Dijkstra；拓扑排不完（出队数 < n）说明有环。

2.9 哈希与复杂度

哈希：用 H(key) 直接把关键字算成地址，平均 O(1) 查到。两个不同 key 算到同一地址就是冲突；装填因子 α = 已存元素 / 表长，α 越大越容易撞。

复杂度链：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ)。

三、基本操作

查找 2 种 · 排序 6 个核心

3.1 顺序查找

从一端开始逐个比，相等就成功，走完没找到就失败。查找第 i 个元素要比较 i 次，失败要 n+1 次，平均 (n+1)/2。

考点：链式存储也能顺序查找，所以"链表不能查"是错的；哨兵放在 0 位可省掉每次的越界判断。

3.2 折半查找

前提：有序 + 顺序存储（要能按下标跳）。每次取中点 Mid 比，比目标大就去左半（High = Mid-1），小就去右半（Low = Mid+1），Low > High 就是失败。

int binarySearch(int a[], int n, int key) {
    int low = 0, high = n - 1;
    while (low <= high) {
        int mid = (low + high) / 2;
        if (a[mid] == key) return mid;        // 命中
        else if (a[mid] > key) high = mid - 1; // 去左半
        else low = mid + 1;                   // 去右半
    }
    return -1;                                // low > high，失败
}

考点：折半只能用于顺序存储的有序表，链表做不了；判定树深度决定最多比几次。

3.3 排序的底层逻辑

一句话：比较两个元素的大小，然后按照规则交换或移动它们的位置。

不用死记代码，按"底层原理 + 生活比喻 + 考试踩坑点"记六种就够。

先记稳定性：两个相等的元素，排完序后原来的前后顺序没变，就叫稳定。稳定：冒泡、插入、归并；不稳定：快排、选择、堆排（口诀"快选堆"）。

为什么不稳定？因为它们会做跨距离的交换/移动，相等的元素可能被互相"越过"。

3.4 六个核心算法

① 冒泡排序 · 最简单，也最慢

原理：相邻两个比大小，大的往后挪；每轮把当前最大"浮"到末尾。

比喻：排队只跟右边的人比身高，你比他高就换位；一轮走完，最高的自动站到队尾。

复杂度：时间 O(n²)，空间 O(1)，稳定（只和相邻的换，不会越过相等元素）。

考试点：效率最低，常被当反面教材；数据基本有序时最好 O(n)。

② 插入排序 · 像打扑克

原理：分"已排好"和"未排好"两段，每次从未排区取一个，插到前面合适位置，比它大的统统后挪一位。

比喻：左手是理好的牌，右手摸一张新牌，看准位置插进左手。

复杂度：时间 O(n²)，空间 O(1)，稳定（相等的不动，插在后面）。

考试点：数据接近有序时极快，接近 O(n)；是希尔排序的基础。

③ 选择排序 · 比武招亲

原理：每趟扫一遍未排区，找到最小的，跟未排区第一个交换。

比喻：每次都在剩下的人里挑最矮的，直接拉到队伍最前面。

复杂度：时间 O(n²)，空间 O(1)，不稳定（跨越式交换会打乱相同元素的先后）。

考试点：不管数据什么样都要扫完，比较次数固定；交换次数最少。

④ 快速排序 · 分治王者（必考）

原理：选一个基准（通常取第一个），比它小的扔左边、大的扔右边（挖坑填数），再对左右两段递归。

比喻：体育课老师喊"比 1 米 8 高的站左边，矮的站右边"，两边再各自找基准继续分队。

复杂度：平均 O(n log n)，最坏 O(n²)，空间 O(log n)，不稳定。

考试点：已排好序时反而最慢（退化），工程上随机选基准规避。

⑤ 归并排序 · 极度稳定（必考）

原理：先对半劈到底（每个只剩一个），再两两合并，合并时谁小谁先出。

比喻：两摞已经排好的扑克，只看两摞最上面谁小，谁小先拿走。

复杂度：时间 O(n log n) 钉死（没有最坏情况），空间 O(n)，稳定。

考试点：唯一"稳定又 O(n log n)"；缺点是费内存，大数据外部排序必用。

⑥ 堆排序 · 选秀淘汰赛

原理：数组看成完全二叉树，建大顶堆；把堆顶（最大值）摘到数组末尾，剩下的重新调整，再摘下一个。

比喻：公司选 CEO，最牛的当堆顶；CEO 辞职（放到最后），剩下的人重新内斗选新 CEO。

复杂度：时间 O(n log n)，空间 O(1)，不稳定。

考试点：空间最省，适合内存受限（嵌入式）；常考大顶堆的建立与调整。

// ① 冒泡：相邻比较，大的往后
void bubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - 1 - i; j++)
            if (a[j] > a[j + 1]) swap(a[j], a[j + 1]);
}

// ② 插入：拿一张牌，插进已排好的位置，比它大的后挪
void insertionSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i], j = i - 1;
        while (j >= 0 && a[j] > key) { a[j + 1] = a[j]; j--; }
        a[j + 1] = key;
    }
}

// ③ 选择：每趟找最小，和未排区第一个交换
void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min = i;
        for (int j = i + 1; j < n; j++) if (a[j] < a[min]) min = j;
        swap(a[i], a[min]);
    }
}

// ④ 快排：挖坑填数，左小右大，再递归
void quickSort(int a[], int low, int high) {
    if (low >= high) return;
    int i = low, j = high, pivot = a[low];
    while (i < j) {
        while (i < j && a[j] >= pivot) j--;
        a[i] = a[j];
        while (i < j && a[i] <= pivot) i++;
        a[j] = a[i];
    }
    a[i] = pivot;
    quickSort(a, low, i - 1);
    quickSort(a, i + 1, high);
}

// ⑤ 归并：对半劈，合并时谁小谁先出
void mergeSort(int a[], int l, int r) {
    if (l >= r) return;
    int m = (l + r) / 2;
    mergeSort(a, l, m);
    mergeSort(a, m + 1, r);
    merge(a, l, m, r);       // 两段各一个指针，小的先拷进临时数组，再整体拷回
}

// ⑥ 堆排：建大顶堆，摘堆顶放末尾，再调整
void heapSort(int a[], int n) {
    for (int i = n / 2 - 1; i >= 0; i--) siftDown(a, i, n);   // 建堆 O(n)
    for (int i = n - 1; i > 0; i--) {
        swap(a[0], a[i]);                                    // 最大值归位
        siftDown(a, 0, i);                                   // 剩下的重新调整
    }
}

3.5 对比表与口诀

算法平均最坏空间稳定性核心特征
冒泡O(n²)O(n²)O(1)稳定效率最低，相邻交换
插入O(n²)O(n²)O(1)稳定局部有序时极快
选择O(n²)O(n²)O(1)不稳定交换次数最少
快排O(n log n)O(n²)O(log n)不稳定已排好序时最慢
归并O(n log n)O(n log n)O(n)稳定唯一稳定且快，费内存
堆排O(n log n)O(n log n)O(1)不稳定空间最省，常考大顶堆

稳定性：冒泡、插入、归并稳定；快排、选择、堆排不稳定——谐音"快选堆"。

速度：带 O(n log n) 的只有三个——快排、归并、堆排。

最坏：快排最坏 O(n²)，归并、堆排最坏仍是 O(n log n)。

空间：归并 O(n)，快排 O(log n)，其余 O(1)。
