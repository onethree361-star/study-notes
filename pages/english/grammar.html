语法结构

英语语法核心三件套：词义辨析 → 动词时态 → 复合从句。从句判断的灵魂是「缺啥补啥」：缺成分用定语从句，缺意思用名词性从句，缺逻辑用状语从句。

共 4 个知识点 · 词义 · 时态 · 从句 · 做题流程
01

词义辨析（后缀分类速记）

后缀预判词性 阅读·完形·写作
看到一个陌生单词，先看后缀就能猜出它是动词还是名词——就像看到"化""性""者"就知道中文词的词性一样。
动词后缀（表动作、使…）
  • -en：widen 拓宽，shorten 缩短，strengthen 加强
  • -ify：simplify 简化，classify 分类，beautify 美化
  • -ate：activate 激活，separate 分开，calculate 计算
名词后缀（表人、物、行为、状态）
  • -tion / -sion：action, decision（动作名词）
  • -ment：agreement, development, movement
  • -er / -or：worker 工人，inventor 发明者（人/工具）
  • -ness：happiness, darkness, kindness（抽象状态）
  • -ity：reality, possibility, ability（性质）
形容词后缀（表属性、特征）
  • -ful：helpful 有帮助的，careful 仔细的
  • -less：hopeless 无望的，careless 粗心的（无…）
  • -able / -ible：acceptable 可接受的，visible 可见的
  • -ous：dangerous 危险的，famous 著名的
副词后缀
  • -ly：大部分形容词 + ly → 副词（quick → quickly）
  • 特例：early、fast 形副同形（既可以做形容词也可以做副词）
速记口诀

en/ify/ate多是动；tion/ment是人物；ful/less/able做形容词；大多ly变副词。

02

动词时态（三层判断模型）

语态+体+时间轴 主将从现 完成时标志词
英语时态不是16个孤立的公式，而是"主动还是被动 + 动作完没完 + 时间落在哪"三个维度的叠加组合。
三层判断模型

第一层：语态（主动/被动）→ 决定用 be+done
第二层：体（动作状态）→ 完成体 have+done / 进行体 be+doing / 一般体 动词原形
第三层：时间轴（过去/现在/将来）→ 决定 have/be 的时态变形

基础构件
  • 完成体：have / has / had + done
  • 进行体：be + doing
  • 一般体：动词原形 / 过去式
  • 被动：be + done
常见时态组合
  • had done：过去完成时（过去的过去）
  • was/were doing：过去进行时（过去某刻正在做）
  • have done：现在完成时（截止现在已完成）
  • am/is/are doing：现在进行时
  • will do：一般将来时
  • will be doing：将来进行时
  • will have done：将来完成时（截止将来某时已完成）
做题红线
  • 主将从现：将来时主句，从句不能随意用过去时（if/when引导的时间/条件状语从句用一般现在时表将来）
  • 完成时标志词：already, yet, since, for, up to now——看到这些词优先选完成时
速记口诀

先看主动还是被动，再看动作完没完、在不在进行，最后看时间落在哪一段。

03

复合从句（缺啥补啥判断体系）

缺成分→定从 缺意思→名从 缺逻辑→状从 陈述语序铁律
三大从句不是靠死记引导词区分，而是看"从句里缺什么"：缺成分补代词，缺意思补连接词，缺逻辑补连词。
总判断流水线（做题顺序固定）

① 先看：从句内部缺不缺主语/宾语成分 → 缺成分 → 定语从句
② 成分齐全，但语义不完整，需要补充解释信息 → 缺意思 → 名词性从句（陈述语序！禁止倒装）
③ 主从句成分、意思都完整，两个独立句子，只需要连接逻辑 → 缺逻辑 → 状语从句

（1）缺成分 → 定语从句

本质：从句相当于形容词，修饰前面的名词（先行词）。

  • 指人作宾语：whom
  • 指物：which
  • 指时间：when（=on which）
  • 指地点：where（=in which）
  • that：人/物都可以，可做主/宾；可用于强调句型

区分：关系代词（that/which/whom）在从句里充当主语、宾语（缺成分才上）；关系副词（when/where）从句本身主谓宾齐全，只缺时间/地点状语。

（2）不缺成分、缺意思 → 名词性从句

本质：从句整体充当主句里的名词（主语、宾语、表语、同位语）。

硬性铁律：名词性从句一律用陈述句语序，不能疑问倒装！

  • what：什么（本身带含义，在从句可充当成分）
  • whether：是否（不能和if互换的场景：介词后、句首）
  • why：为何
  • how：如何、怎样
  • when / where：何时 / 何地

同位语 vs 定语从句：同位语从句解释前面名词内容本身（The news that our team won is true.），定语从句是修饰限定名词。

（3）不缺成分、不缺意思，缺逻辑 → 状语从句

本质：从句相当于副词，修饰主句动作，交代主句的逻辑背景。

  • 转折：although/though（虽然）, but（但是）
  • 原因：because, since, as
  • 条件：if, unless（除非），主将从现考点
  • 让步：even if（即使）
  • 目的：so that（为了）
  • 结果：so…that…（如此…以至于）
  • 时间：when, while, before, after, until
  • 对比/方式：as（像…一样）
04

考场做题一步流

长难句拆解 固定流程
拿到一个长难句不要慌，按四步走，再长的句子也能拆明白。
四步拆解流程
  • 第一步：划出主句、从句（找谓语动词，一个句子只有一个谓语）
  • 第二步：判断从句内部：缺主/宾吗？→ 缺 = 定语从句，找先行词
  • 第三步：不缺成分？意思讲完了吗？→ 意思没讲全 = 名词性从句，牢记陈述语序
  • 第四步：意思完整通顺？→ 状语从句，判断逻辑关系（转折/原因/条件/时间…）
速记口诀

缺成分找先行词（定从），缺意思补连接词（名从），缺逻辑加连词（状从）。
两个句子都完整，连词只管逻辑，不充当句子成分。
